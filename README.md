# Quinti

דף בית בסגנון גוגל לחיפוש שאלות מנהלים (מנכ"ל / גזבר / מנמ"ר / ראש העיר) מתוך ה-DWH העירוני, עם קיצורי דרך לדשבורדים ב-Power BI.

## הרצה

הפרויקט הוא קובץ HTML עצמאי אחד ללא תלויות:

```bash
open index.html
```

או להריץ שרת סטטי מקומי:

```bash
python3 -m http.server 8080
```

ולגלוש ל-http://localhost:8080

## מבנה

- `index.html` – כל הממשק: עיצוב, נתוני דמה (`DATA`, `SHORTCUTS`) ולוגיקת החיפוש והתוצאות.

## חיבור לנתונים אמיתיים

1. להחליף את מערך `DATA` בקריאה לשירות שמחזיר שאלות מה-DWH (שדות: `q`, `who`, `date`, `kpi`, `ans`, `src`, `etl`, `pbi`, `tags`, `trend`).
2. להחליף את קישורי הדמה ב-`SHORTCUTS` בכתובות דוחות Power BI אמיתיות.
